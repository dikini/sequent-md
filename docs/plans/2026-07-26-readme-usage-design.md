# README Usage and Navigation Design

## Purpose

Turn the README into a concise landing page that explains how to use and
configure the renderer and directs readers to the detailed references.

## Decisions

- Include quick-start, core, rehype, and VS Code usage paths.
- Describe the supported `symbols` configuration as a merge/override map.
- Summarize axiom, sibling, nested, and family source forms without duplicating
  the full grammar.
- Link directly to the guide, grammar reference, and every example document.

## Validation

Keep code snippets aligned with exported APIs and run the normal test/build
suite after the Markdown change.
